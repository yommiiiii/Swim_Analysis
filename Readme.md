# 🏊‍♂️ 개인 수영 기록 추이 변화 프로그램 (Swim Log)

본인의 대회 기록을 체계적으로 축적하고, 성장을 한눈에 확인할 수 있는 시각화 기반의 기록 추이 변화 프로그램입니다. 데이터는 개인 로컬 환경에 안전하게 저장됩니다. 📊

---

## 🛠️ 실행 전 준비사항 (최초 1회 설정)

이 프로그램을 실행하기 위해서는 **Python 3** 환경과 그래프 시각화를 위한 **외부 라이브러리** 설치가 필수적입니다. 

VS Code 터미널을 열고 아래 명령어를 입력하여 필요한 패키지를 설치해 주세요.
```bash
pip install matplotlib
```
*※ 시스템 환경에 따라 `pip3 install matplotlib`로 입력해야 할 수도 있습니다.*

---

## 🚀 프로그램 실행 명령어

준비가 완료되었다면 프로그램이 있는 폴더 터미널에서 아래 명령어를 실행합니다.
```bash
python3 analysis.py
```

### 💡 주요 기능 및 흐름
1. **`1`번 입력 (기록 추가):** 대회 이름, 세부 종목, 기록(초 단위 숫자)을 입력합니다. 첫 입력 시 자동으로 데이터베이스 파일(`swim_records_detailed.json`)이 생성됩니다.
2. **`2`번 입력 (기록 추이 시각화):** 누적된 데이터를 바탕으로 종목별 기록 변화가 꺾은선 차트(Matplotlib)로 팝업됩니다. 📈

---

## ⚠️ 주의사항
* 개인 기록 데이터인 `swim_records_detailed.json` 파일은 오픈소스로 공유되지 않도록 `.gitignore` 처리가 되어 있습니다. 각자 로컬 컴퓨터에서만 기록이 누적됩니다.
* 기록 입력 시 오타가 나면 그래프 꺾은선이 왜곡될 수 있으므로 정확한 소수점 포함 초 단위 숫자로 입력해 주세요!
